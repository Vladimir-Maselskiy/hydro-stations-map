# Тестове завдання: карта станцій вимірювання рівня води

## Завдання

Розробіть інтерфейс карти станцій вимірювання рівня води. Допоможіть користувачу знайти цікаву йому станцію (зазвичай у цікавій для користувача локації) та переглянути кілька її останніх вимірів, щоб зрозуміти динаміку рівня води.

У пакеті є стартовий проєкт Vue 3, локальний API й синтетичні дані. Дані станцій і вимірювань стабільні між запитами, тому перекривні області карти повертають ті самі станції в тих самих місцях. API запускається разом із frontend dev-сервером; окремо встановлювати або запускати бекенд не потрібно. Ендпоінти та параметри API описані у Swagger за адресою `http://127.0.0.1:5173/docs/`. Вимоги навмисно не визначають макет, бібліотеку карти чи точний перелік елементів. Оберіть рішення, яке вважаєте доречним, використовуйте API та зафіксуйте важливі припущення.

Запити до наданих ендпоінтів `/api/*` можуть випадково повертати HTTP `503`; це очікувані відповіді тестового середовища. Документація та перевірка доступності API від цих випадкових помилок не залежать.

Можете використовувати будь-які інструменти. Для нас важливий готовий результат. Під час обговорення тестового розкажіть, які інструменти використовували, як організували роботу та перевіряли результат.

Зверніть увагу на те, щоб UX відчувався завершеним, не сирим і не кривим.
